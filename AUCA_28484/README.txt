AUCA_ID - School Management System (console, Java 17+)

Compile (from inside the AUCA_ID folder):
  Linux/Mac: javac -d out $(find src -name "*.java")
  Windows  : dir /s /b src\*.java > files.txt  &&  javac -d out @files.txt

Run:
  java -cp out com.auca.main.Main

Form commands: type BACK (previous field) or CANCEL (discard) at any prompt.
Study year rule used: 1-6 (Section 8 of the question).
